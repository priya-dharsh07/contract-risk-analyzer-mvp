## Contract Risk Analyzer MVP

An AI-powered web application that analyzes contracts and identifies potential risks, missing clauses, and areas that may require attention.

### Features
Upload and analyze PDF contracts
Contract risk assessment
Risk score and risk level
Contract summary
Clause extraction
Missing clause detection
AI recommendations
AI Contract Builder
Clause Marketplace
Live Contract Editor
Word download and printing
Tech Stack
React
Python
FastAPI
LLM API
PDF Text Extraction

### Project Type

MVP / API-based prototype for AI-powered contract analysis and generation.
